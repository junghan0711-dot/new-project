# 各部會補助計畫申請文件庫

這是公司政府計畫與地方創生提案用的本機文件庫。

- `INDEX.md`：查找入口與維護規則。
- `下載與撰寫SOP.md`：協助單位找補助、下載格式文件、建立個案資料夾與撰寫計畫書的標準流程。
- `manifest.csv`：本機已保存文件清單。
- `official-gov-plan-list.csv`：從國發會地方創生資訊共享交流平臺「部會資源」API 抓取的目前清單。
- `official-resource-links.csv`：官方 API 直接列出的附件連結。
- `official-resource-downloads.csv`：附件自動下載紀錄；目前官方附件連結對自動下載回 403，需用瀏覽器手動補檔。
- `files/`：本機原始文件副本，已被 `.gitignore` 排除。

官方來源：https://www.twrr.ndc.gov.tw/case/gov-plan
