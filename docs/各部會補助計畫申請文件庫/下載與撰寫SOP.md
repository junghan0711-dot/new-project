# 補助格式文件下載與計畫撰寫 SOP

> 目的：未來協助單位申請各部會補助時，能快速找到對應部會的最新申請格式文件，建立個案資料夾，並依補助規定完成計畫書、附件與送件檢核。

## 一、收到需求時先問 8 件事

| 欄位 | 要問清楚的內容 | 用途 |
|---|---|---|
| 申請單位 | 公司、協會、基金會、合作社、學校、地方政府、個人 | 判斷申請資格 |
| 所在地 | 縣市、鄉鎮、場域、是否偏鄉/原鄉/客庄/農村/漁村 | 對應部會與加分條件 |
| 想做的事 | 產業發展、文化保存、觀光遊程、農業升級、就業培力、空間活化、照顧服務、循環永續 | 篩選計畫範疇 |
| 主要對象 | 青年、長者、社區、農民、企業、店家、旅客、地方團隊 | 判斷補助目的是否吻合 |
| 目前資源 | 已有場地、團隊、人力、營收、合作夥伴、地方政府支持 | 判斷可行性與配套 |
| 需求金額 | 想申請多少、是否有自籌款、是否能先墊付 | 判斷補助上限與財務風險 |
| 截止日 | 公告日期、收件截止、是否需線上申請 | 排工作排程 |
| 交付需求 | 只協助找補助、撰寫計畫書、整理附件、代做簡報、送件前檢核 | 決定工作範圍 |

## 二、先做補助媒合

使用兩份清單交叉比對：

1. `official-gov-plan-list.csv`：官方部會資源清單，適合找目前網站列出的計畫。
2. `manifest.csv`：本機已保存文件清單，適合找申請須知、作業要點、計畫書格式與附件表單。

## 三、下載對應部會格式文件

### A. 先查本機文件庫

1. 開啟 `manifest.csv`。
2. 用「部會/來源」篩選目標部會。
3. 用「文件用途」篩選：
   - `申請須知/作業須知`
   - `補助要點/作業規範`
   - `計畫書格式/範本`
   - `申請表件/表格`
   - `評分/審查`
4. 找到本機相對路徑後，從 `files/` 複製一份到個案工作資料夾，不要直接改原始檔。

### B. 再查官方網站最新版本

1. 開啟官方頁：<https://www.twrr.ndc.gov.tw/case/gov-plan>
2. 依需求篩選：
   - 申請/提案對象：個人、企業、縣市政府、機構團體、其他
   - 計畫範疇：文創史蹟、公共服務建設、產業/事業發展、農業產業升級、觀光旅遊發展、科技導入應用
   - 資源類型：融資補助、人才育成、環境建設、經營輔導
3. 點開計畫的 `planLink` 或官方附件。
4. 下載最新申請須知、計畫書格式、附件表單、評分標準、經費編列表。
5. 檔名加上下載日或公告日，例如：
   - `20260709_文化部_地方創生文化環境營造_申請表件.odt`
   - `20260709_經濟部_SBTR城鄉創生轉型_申請須知.pdf`

> 注意：官方 API 的附件連結有時會對自動下載回 `403`，這時用瀏覽器手動下載即可；連結已保留在 `official-resource-links.csv`。

### C. 若官方頁沒有附件

1. 以計畫名稱到主管部會官網搜尋。
2. 優先使用官方網域、公告頁、補助專區或法規資料庫。
3. 下載後記錄來源網址、公告日期、下載日期。
4. 新增到 `files/<部會>/<計畫名稱>/`，再更新 `manifest.csv`。

## 四、建立個案工作資料夾

若只是協助撰寫草稿，先放在工作桌：

```text
outputs/<YYYYMMDD>_<單位簡稱>_<補助計畫名稱>/
  00_來源文件/
  01_訪談資料/
  02_計畫書草稿/
  03_附件表單/
  04_預算與時程/
  05_送件檢核/
```

若已確定是公司正式承接案，完成後要回存到：

```text
/Users/junghanchiu/2026 Data base/專案庫/<辦公室>/<專案附件資料夾>/
```

並更新對應 `專案-*.md` 的「專案文件」與「進度紀錄」。

## 五、協助撰寫流程

### 第 1 步：資格與風險快篩

先讀申請須知與補助要點，輸出一頁判斷：

| 項目 | 判斷 |
|---|---|
| 申請資格 | 可申請 / 需合作單位 / 不適合 |
| 補助上限 | 金額、比例、自籌款 |
| 必備附件 | 登記證明、財務資料、合作意向書、場地證明、簡報、經費表 |
| 審查重點 | 地方性、創新性、可行性、永續性、財務合理性、過往實績 |
| 風險 | 截止日太近、資格不足、自籌不足、缺合作證明、經費不能核銷 |

### 第 2 步：把單位需求轉成補助語言

| 單位原始說法 | 計畫書要改寫成 |
|---|---|
| 想辦活動 | 建立地方參與機制、帶動人流、形成可持續營運模式 |
| 想修空間 | 活化公共服務場域、改善地方創生基礎環境 |
| 想賣產品 | 建立在地產業品牌、拓展通路、提高地方收益 |
| 想請人 | 建立穩定服務量能、培育在地人才、創造就業 |
| 想做課程 | 培力地方團隊、建立知識工具、形成後續行動方案 |

### 第 3 步：依官方格式先搭骨架

不可自己發明章節順序；先以官方計畫書格式為主。若官方沒有格式，使用通用骨架：

1. 計畫摘要
2. 申請單位與地方背景
3. 問題診斷與需求分析
4. 計畫目標
5. 執行策略與工作項目
6. 執行時程
7. 人力分工與合作網絡
8. 預期成果與量化指標
9. 經費需求與自籌配套
10. 永續營運與風險管理
11. 附件清單

### 第 4 步：先做三張表

| 表格 | 目的 |
|---|---|
| 工作項目表 | 把活動、輔導、採購、宣傳、行政管理拆成可執行任務 |
| 預算對照表 | 每筆經費對應工作項目、補助科目、估價依據 |
| 審查指標對照表 | 每個審查項目都能在計畫書找到答案 |

### 第 5 步：產出文件

依需求交付：

- `資格快篩與補助媒合建議.md`
- `計畫書_v1.docx`
- `經費預算表.xlsx`
- `附件清單與缺件表.md`
- `送件前檢核表.md`
- 若需要簡報，再做 `簡報_v1.pptx`

## 六、送件前檢核

| 檢核項目 | 狀態 |
|---|---|
| 使用最新版申請須知與表件 | □ |
| 申請資格符合 | □ |
| 計畫書章節與官方格式一致 | □ |
| 經費科目符合補助規定 | □ |
| 自籌款、配合款、民間投資寫法一致 | □ |
| 附件完整，檔名符合規定 | □ |
| 用印、簽章、負責人資料完成 | □ |
| 線上申請帳號與上傳格式確認 | □ |
| 截止日前至少 1 天完成最終版 | □ |
| 正式送件檔已回存專案資料夾 | □ |
