# 各部會補助計畫申請文件庫

> 用途：集中保存各部會地方創生／補助計畫的申請須知、作業要點、計畫書格式、附件表單與政策核定本。
> 本地文件副本位於 `files/`，此資料夾已由本層 `.gitignore` 排除，不會進入公開 repo。

## 快速使用

1. 先開 `official-gov-plan-list.csv` 查官方網站目前列出的 115 筆部會資源。
2. 再開 `manifest.csv` 找本機已保存的原始文件。
3. 寫計畫書時優先找「計畫書格式/範本」與「申請表件/表格」；查資格與經費限制時看「申請須知/作業須知」與「補助要點/作業規範」。
4. 需要最新版本時回到官方來源頁確認公告日期與附件版本。

## 維護規則

- 新增檔案放入 `files/<部會>/<計畫或用途>/`。
- 檔名保留年度、計畫名、文件用途；若同名不同版本，補上公告日期或下載日期。
- 每次補檔後重建 `manifest.csv`，並在需要時更新此索引。
- `files/` 是本機文件庫，不主動加入 git；要公開分享時改輸出精簡清單或雲端連結。
